# Used Car Price Prediction

## About

This project focuses on analyzing a used car dataset, creating an interactive Power BI dashboard, and building machine learning models to predict used car prices.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Power BI

---

## Data Science

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Outlier Detection

---

## Power BI Dashboard

- KPI Cards
- Brand Analysis
- Price Analysis
- Fuel Type Distribution
- Transmission Distribution
- Location-wise Analysis
- Interactive Filters

---

## Machine Learning

Regression Models Used:
- Multiple Linear Regression
- Ridge Regression

Evaluation Metrics:
- MAE
- MSE
- RMSE
- R² Score

---

## Dataset

Used Car Price Prediction Dataset taken from Kaggle: https://www.kaggle.com/datasets/sujay1844/used-car-prices
